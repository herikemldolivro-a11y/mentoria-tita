## Regra para os próximos PDFs

Até o PDF de uma aula ser fornecido, a plataforma cadastra somente o escopo indicado pelo nome da aula, sem inventar subtópicos. Quando o material chegar, a matriz de tópicos da aula deve ser refinada para refletir exatamente o conteúdo efetivamente ensinado.
